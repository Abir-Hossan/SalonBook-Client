# SalonBook — Client

Phase 01 frontend implementation for the SalonBook luxury salon booking platform. Built with Next.js App Router, React, TypeScript, and Tailwind CSS 4.

The frontend currently uses isolated mock data under `src/mock/`. Authentication, API, database, Stripe, and ImgBB are intentionally not connected in this phase.

See the full setup, feature list, and test commands in this README after the Phase 01 source upload is complete.
